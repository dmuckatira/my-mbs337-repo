# Homework 9

This homework builds a linear classifier to predict whether a breast cancer tumor is malignant or benign using the UCI Breast Cancer Wisconsin Dataset from `sklearn`. It demonstrates how to load and explore a dataset, split data into training and test sets, train a Perceptron-based classifier using Stochastic Gradient Descent, and evaluate model performance using accuracy scores and a confusion matrix.

## Launching the Notebook

Install dependencies:

    pip install -r requirements.txt

Start the Jupyter server by running this in the terminal:

    jupyter notebook

Open up your Jupyter notebook in a browser using ipaddress:port/lab
Then open `Notebook.ipynb` from the Jupyter file browser that appears in your browser and run the cells.
